Kết nối & theo dõi sự kiện

Polling nghĩa là trang web này tự động gọi lại API mỗi vài giây để hỏi "có gì mới không" — khác với WebSocket là backend tự đẩy dữ liệu xuống. Vì FastAPI hiện chỉ có REST (GET /api/events), polling là cách đơn giản nhất, không cần sửa backend.

Nếu console trình duyệt báo lỗi CORS (bị chặn vì trang web và API khác gốc/địa chỉ): cần thêm CORSMiddleware vào FastAPI của Khánh, cho phép origin là nơi mở file này (ví dụ null nếu mở file trực tiếp, hoặc domain thật nếu host lên server).

Bấm vào từng dòng sự kiện để xem raw JSON — dùng để đối chiếu tên field/cột thực tế backend trả về có khớp với mqtt_schema.json / api_contract.md không.
